# Labels

This subfolder contains the annotation data for the Open Kidney Ultrasound Data Set.

## Contents

- **CSV files** (`reviewed_labels_1.csv`, `reviewed_labels_2.csv`) — Annotations generated using the [VGG Image Annotator](https://www.robots.ox.ac.uk/~vgg/software/via/). Each CSV corresponds to one expert sonographer's annotations.
- **Mask directories** (`reviewed_masks_1/`, `reviewed_masks_2/`) — Pre-generated binary segmentation masks organized by anatomical class (`capsule/`, `regions/`).

## CSV Format

Each record in the CSV files includes:

| Field | Description |
|-------|-------------|
| Filename | Image file name |
| File size | Size of the image file in bytes |
| Quality | Subjective quality rating from the sonographer |
| View type | Ultrasound view (transverse, longitudinal, other) |
| Comments | Brief notes from the sonographer |
| Polygon coordinates | Manually drawn polygon vertices for each annotated region |

Polygon coordinates are manually generated by each individual sonographer and define the boundaries of four anatomical classes.
